# Adulting 101 - Intro to Computer Science Project - 12/11/2024

This project, **Adulting 101**, was created as part of an **Intro to Computer Science** course. The goal was to apply basic HTML and CSS skills to make a functional, educational website that demonstrates understanding of web development fundamentals.

---

## 🧩 Project Overview

**Adulting 101** is a beginner-friendly website that teaches basic life skills for young adults. It was designed as a class project to show:

- Structuring web pages with **HTML**
- Styling pages using **CSS**
- Using **navigation bars, dropdown menus, and sections** effectively
- Linking multiple pages together
- Presenting information in a clean and readable format

The website includes sections for:

- **Taxes** – Intro to filing tax returns and understanding deductions  
- **Jobs** – Resume tips, interviews, and career advice  
- **Property** – Renting and buying your first home  

It also includes **featured articles** and **testimonials** to demonstrate layout and content organization skills.

---

## 💻 What I Learned

While building this project, I practiced:

- HTML page structure and semantic elements (`<nav>`, `<section>`, `<footer>`, etc.)
- Creating a **responsive navigation bar** with dropdown menus
- Styling with CSS, including flexbox layout for navigation and sections
- Organizing content across multiple pages
- Linking internal and external resources  

This project shows how I applied basic web development concepts in a small, functional website.
